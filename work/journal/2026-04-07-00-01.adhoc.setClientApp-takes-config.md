## Request

Merge `createClientApp` and `setClientApp` — `setClientApp` should accept a `ClientConfig`, create the app internally, and set it in context.

## What Was Done

- `src/lib/client/index.ts` — `createClientApp` removed from public API; its logic folded into `setClientApp(config: ClientConfig)`.
- `src/routes/+layout.svelte` — call site simplified from `setClientApp(createClientApp(createClientConfig()))` to `setClientApp(createClientConfig())`.
- `work/docs/guides/client-app.md` — init example updated to match.

## Notes

`ClientApp` type is still exported (needed by consumers of `getClientApp()`). Only `createClientApp` was removed — it was never intended as a public primitive; `setClientApp` is the correct entry point for initialization.
